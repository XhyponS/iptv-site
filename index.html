Add your own channels

Open channels.js and edit the array. Each entry needs a channel number, a name, and either a src (a direct stream) or an embed (an iframe embed URL) — not both.

// direct stream (plays in the built-in player)
{ num: "01", name: "My Channel", src: "https://example.com/stream.m3u8" }

// iframe embed (loads a provider's own player)
{ num: "02", name: "My Other Channel", embed: "https://example.com/embed/xyz" }

Only add channels you actually have the right to use — your own IPTV subscription's stream or embed links, a self-hosted stream, or content you have permission to distribute. This page is just the tuner; it doesn't come with any real channels built in, only placeholder demos.
